# Лекція 2 · Проводка captured

PAM отримав від PSP: цей `deposit_id` / `psp_transaction_id` = **captured**, $50.

Касир не робить `balance += 50`. PAM пише **проводку**: два боки однієї суми.

## Навіщо два боки

Гроші не з’являються з повітря. Якщо гравець «має» $50, казино **комусь винен** $50, і десь лежить актив (на PSP / мерчант-рахунку).

| Рахунок | Сенс після captured $50 |
|---|---|
| `cash_at_psp` | у нас з’явились гроші (актив) |
| `player_cash` | ми винні гравцю $50 (можна ставити) |

Одна проводка:

```
debit   cash_at_psp    $50
credit  player_cash    $50
ключ    deposit_id=dep_1   (або psp_transaction_id)
```

Сума по книзі лишається зведеною: +50 актив, +50 зобов’язання.

## Що не проводка

- статус заявки `pending` (це ще не гроші)
- «Success» у касирі
- другий вебхук того ж `dep_1` — **немає другої проводки** (ідемпотентність)

## Касир після цього

Показує доступно **$50**, бо так сказав ledger, не PSP напряму.
