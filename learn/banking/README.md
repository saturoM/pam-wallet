# Banking money path

Короткий трек для **Technical PM** після iGaming/PAM (`pam-wallet` learn 01–11).

Мета: вміти зібрати в голові **банківський money path** (рахунок → рейл → картка → BaaS/ліцензія → KYB), не плутаючи його з «відкрити банк з нуля».

## Як проходити

1. Читай лекцію (одна ідея).
2. Зроби exercise (відкриті відповіді).
3. Закрий модуль, коли можеш пояснити sequence іншому PM.
4. Тримай міст з PAM: колонка `bridge` у `syllabus.json`.
