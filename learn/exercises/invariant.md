# Практика · інваріант

Лекція: `career/learn/invariant.md`.  
Своїми словами. PAM decision log не відкривай.

## 1. Класифікація

Для кожного: **інваріант / вимога / задача / метрика**. Чому (одне речення).

1. Хочемо, щоб депозит проходив менше ніж за хвилину.
2. Намалювати бейдж «Processing» на касирі.
3. Два боки кожної проводки: сума debit = сума credit.
4. Скільки разів за тиждень прийшов другий webhook того ж платежу і книга все одно +$50 двічі.
5. Кнопка Withdraw завжди активна.

## 2. Зроби інваріант

Ситуація (вигадана, не PAM): інтернет-магазин. Клієнт «оплатив», склад ще не підтвердив наявність.

Напиши **одне** речення-інваріант про гроші або товар (тип: зведення / заборона / ідемпотентність).  
Потім одну дію, яка **не** ламає його, і одну, яка **ламає**.

## 3. Тези

Закрий лекцію. Три речення:

- Інваріант це …
- Інваріант це не …
- Метрика до інваріанта ставиться так: …

Коли відповіси — розберемо.
