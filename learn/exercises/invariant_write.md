# Практика · сформулювати інваріант

Лекція: `career/learn/invariant_write.md`. PAM decision log не відкривай.

## 1. Перепиши або відкинь

Для кожного: або **не інваріант** (що саме: wish / задача / спека кроку), або одне речення в шаблоні завжди / ніколи / той самий ключ.

1. Користувач не повинен злитися.
2. Спочатку показуємо спінер, потім Success.
3. Другий лист «оплата ок» з тим самим id платежу не додає других грошей на рахунок.
4. Баланс має бути правильний.
5. Зробити тост «вже оброблено».

## 2. Гардероб

Є інваріант: кількість пальто = кількість «живих» номерків.

1. Людина в черзі, номерка ще немає. Ламає? Чому?
2. Видали номерок, пальто повісили. Ламає? Чому?
3. Той самий номерок показали вдруге, друге пальто не віддали. Ламає зведення? Який інший інваріант тут тримається?

## 3. Одне речення PO

Допиши фразу, якою віддаєш інваріант інженеру (без слова «надійніше»).

Коли відповіси — розберемо.
