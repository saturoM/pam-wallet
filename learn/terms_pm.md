# Терміни · PM / PAM (короткий словник)

Одне речення на слово. PAM — лише як якір, не нова теорія.

## Уже були

| Термін | Що це |
|---|---|
| **Спека** | Як має працювати (креслення). Не «чому так». |
| **Decision log** | Журнал вибору на розвилці: взяли / вбили / чому. |
| **Рішення** | Були варіанти, решту відкинули. |
| **Факт** | Спостереження («webhook приходить двічі»). Що з ним робити — уже рішення. |
| **Задача** | Робота в беклозі («намалювати бейдж»). |
| **Інваріант** | Речення про стан, яке завжди має бути правдою. Порушення = зламана модель. |
| **Метрика** | Як у проді ловимо, що інваріант збрехав. |

## Гроші (з лекцій 1–5)

| Термін | Що це |
|---|---|
| **TAKE** | Намір. Клік, заявка. Ще не факт у книзі. |
| **FILL** | Факт, який уже можна провести. Captured, settle, approve KYC. |
| **Ledger / книга** | Єдине місце, де живуть гроші. Касир і гра лише читають. |
| **Проводка** | Один рядок книги: два боки тієї самої суми + ключ. |
| **Ключ** | Id факту (`dep_1`, `rnd_1`), щоб повтор листа не став другим фактом. |
| **Ідемпотентність** | Той самий ключ удруге не змінює книгу. |

## Ще три, без яких далі важко

| Термін | Що це |
|---|---|
| **Gate** | Дозвіл/заборона **до** книги (ліміт, freeze). Deny — не проводка. |
| **Acceptance** (критерій приймання) | Як PO каже «готово»: конкретний знімок ок / не ок. Часто = інваріант + 1 приклад. |
| **Recon** | Звірка двох картин (книга vs PSP vs каса). Ловить, що інваріант уже збрехав. |

## Не плутати пари

- Спека ≠ лог: як працює vs чому так обрали.
- Інваріант ≠ метрика: правда про стан vs лічильник у проді.
- TAKE ≠ FILL: клік vs гроші/підпис у книзі.
- Gate ≠ проводка: «не пустили» vs «переклали $».
- Задача ≠ рішення: зробити екран vs заборонити касиру писати баланс.
